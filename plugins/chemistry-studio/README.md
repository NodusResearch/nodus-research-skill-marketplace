# Chemistry Studio source compatibility

The 2.6 and 2.7 source versions target Nodus 5.9.1 and Capability API v2. They are checked against the Nodus source build at [5ebe54a](https://github.com/jorgepb96/nodus/commit/5ebe54aecd57e92e22d4cfc18f132c812b68f9ac).

`execute-route-program` is an application-invoked alternate input to the existing route audit. Ordinary synthesis answers retain the host's appended output contract. Generated equations are audited for structures, balance, continuity and stereochemistry; toolkit execution does not establish experimental feasibility or a literature precedent.

Automatic Research decomposition requires the host integration in [Nodus #1114](https://github.com/jorgepb96/nodus/pull/1114). The optional local monomer library is not bundled. Missing libraries return unidentified capped fragments; unavailable decomposition retains whole-target searches in the host.

A merged source version is not a signed release. Installable updates require the protected maintainer release workflow documented in the repository's CONTRIBUTING.md. No signing or publication occurs in the pull-request checks.
